# Character avatars

The 30 approved, transparent 64 × 64 PNG character portraits are bundled here
in the review order maintained by `src/lib/character-avatars.ts`. The picker
stores an inline PNG through the existing `profiles.set_asset` API, not a
build-specific asset URL. No runtime dependency on the source scratch files.

The flower-wreath portrait's original attribution is unverified. Its label is
intentionally neutral: “戴花环的女子” / “Woman with a Floral Hat”.
